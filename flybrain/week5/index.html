B trials in one CUDA graph

The science datasets are many independent trials on one network (for example 120 hidden-state episodes, each with its own stimulus and state drive). One trial leaves the GPU mostly idle, so P1 runs B trials side by side in one step on an RTX 5060 Ti. They share the wiring, and each trial keeps its own seed, its own stimulus blocks and its own spike buffers. One captured CUDA graph is replayed per step for the whole batch. Everything is in float64, the precision used for every check.

Float64 unless marked. Medians of 5 runs. Same session, one trial alone: the Week 4 GPU graph runs at 0.44 ms per step (0.231 trials/s) and the PC's CPU at 0.60 ms (0.168 trials/s). No other simulation was running during any timed row (checked before and after each). No trial exceeded its spike or synapse cap.

What held

  • Each trial is spike-for-spike the same as running it alone. On the CPU, the spike times and final voltages are bitwise equal to the reference simulator. On the GPU, a trial gives the same spike counts alone and in a batch of 8 (tested in two slots each, three seeds), and the same counts as the GPU reference (8 seeds, 0 neurons differ).
  • Different stimuli per trial work. Each step replays one graph, also with 8 different stimulus schedules.

What didn't

  • 8 trials take 2.0 ms per step, not under 1 ms. Throughput stops growing at B = 8. A batch of 8 runs 1.7× the single-trial GPU graph and 2.4× the CPU, and larger batches add nothing.
  • Why: the number of GPU kernels per step hardly changes (173 at B = 1, 180 at B = 8). Their work grows instead:
    • Every trial reads its full fixed-size synapse buffers each step (about 98,000 entries), however few neurons spiked.
    • Above about 8 trials, the neuron state no longer fits the GPU's 32 MB L2 cache, so the voltage update slows faster than B grows.
    Fusing these steps into fewer kernels is the next GPU target.
  • Exact match costs some flexibility. To match the reference exactly, each trial draws the same random numbers as the reference does. That means one graph per set of stimulus windows (11 graphs for the 8-schedule batch). A batch with its own random stream needs only one graph, but it is then a different random realization of each trial, and two realizations agree only to a correlation of 0.986–0.996.
